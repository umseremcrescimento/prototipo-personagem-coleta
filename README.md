**Aluno:** [Weliton Nunes de Oliveira] 
**Turma:** [2026.29.09] 
**Feito com:** Unity 6 e C# 
## Sobre o projeto 
O jogo se baseia no jogador controlar um personagem em forma cilíndrica e pegar maças.
## O que o projeto faz 
- o jogador movimenta o personagem com WASD
- ao encostar nos itens, eles somem e o placar aumenta
- quando coleta tudo, aparece a mensagem de vitória
- se o jogador apertar space ele pula
## O que o projeto contém 
**Cenas:** nenhuma
**Scripts:** Camera: faz a camera seguir o jogador; Comidapegar: Permite que o objeto suma depois do jogador tocar e adicionar pontos para a pontuação;
Movimento: um contabilizador para contar os pontos que o jogador pega aparecer a tela de vitória; Movimento2: fazer o jogador poder andar e pular; rotacao: fazer a maça girar.
**Objetos principais:** Sphere (3), PickUp, Goat e Plane.
**Recursos usados:** Rigidbody, Collider com Is trigger e sem e TextMeshPro
## Controles 
WASD – Faz o jogador poder andar para frente, para tras, esquerda e direita.
## O que eu aprendi
A fazer a tela de vitória, o que o Header faz no script e a modelar objetos no Blender.
